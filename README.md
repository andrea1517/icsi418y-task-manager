# ICSI418Y - Programming Assignment 1: The Task Manager

- **Author:** Andrea Ye
- **Application Name:** The Task Manager

## Application Description
This is a basic client-side task manager application built using vanilla **HTML**, **CSS**, and **JavaScript**.

This task manager application allows for its user to enter in the name of their task(s) and select a priority level (`low`, `medium`, or `high`). Users are able to mark their task(s) as completed or delete them at any time using the 'Complete' and 'Delete' buttons.

## How to Run the Application
1. Clone this repository.
```bash
git clone https://github.com/andrea1517/icsi418y-task-manager.git
```
2. Open the `index.html` file in your web browser.

## Incomplete Features
This task manager currently does not have a save data feature.
